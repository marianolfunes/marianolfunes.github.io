AI integration

Supercemento · August 2026 · preliminary

Objective. Integrate AI into the company's processes and activities — first as a tool, then as standard practice.

Stages

Assessment

Assessment of what the business requires and how IT supplies it.

  • The business. How the organisation is set up, which core processes run on software, and how the managers of those areas see AI.
  • IT. Its people and resources, the software stack, the plan, the technical debt, what is already planned for AI, and what has been attempted before.

The output is the plan revised and sized.

General productivity — app

Context

Enterprise LLM applications are licensed per user and integrated into the workplace suite. As of August 2026 the main products are Claude, ChatGPT Enterprise, Microsoft Copilot and Google Gemini. Claude was selected on 25 August 2026.

Market leaders have deployed across their organisations. Accenture is rolling out to about 743,000 people. JPMorgan reached 200,000 users in eight months. Goldman Sachs went firmwide after piloting with 10,000. In the construction sector, Techint deployed Microsoft Copilot at the end of 2025.

The implementation:

  1. Standard training
  2. Discovery and development workshops
  3. Support applying it to each user's processes

Uses

General. Excel, document review, data extraction, analysis, tendering, contract administration, procurement, cost and planning, site. For example: pliego analysis into a requirements checklist, subcontractor quote comparison, price redetermination. Advanced. Automated tasks, scheduled or recurring, and connections to the company's own applications.

IT technical productivity — coding tools

Context

"We are at the point where AI is writing most of the code. We have almost complete automation of code writing." — David Sacks, May 2026

"I would never hire a finance person who didn't know how to use Excel, and I pretty much probably wouldn't hire a finance person today that doesn't know how to use a tool like Codex." — Sarah Friar, Chief Financial Officer of OpenAI, June 2026

AI coding tools are LLM applications for software development. As of August 2026 the main tools are Claude Code, Codex, Cursor, GitHub Copilot and Gemini Code Assist.

The tool reaches the code, the command line and the systems themselves. For a technical user that is the working interface to the company's software, and the ground for development projects.

Rolled out to IT, and open to any user with the technical capability for it.

Technical debt — software

Context

"We have 50 years of accumulated tech debt as a world… hundreds of trillions of lines of just pretty marginal, mediocre code to bad code." — Chamath Palihapitiya, April 2026

Assessment provides IT's plan, the software each core process runs on, and the processes running on none. Old software and no software are the same debt.

AI coding tools change the cost equation of writing code, testing it and migrating data, and with it the total cost of producing an application. Work that could not justify a project before can now, on either route.

Two delivery routes:

  • Outsourced. A vendor product as it comes, a vendor product adapted, or a firm engaged to develop.
  • Internally led. People from IT with AI coding tools, in short cycles with the user present.

Process automation — agents

Context

"An agent is an application that completes a task by planning its own steps and calling tools." — Anthropic

"End-to-end process redesign is what separates organizations that achieve 60% cost reductions from those that capture less than 20%." — BCG, on its agentic deployments, June 2026

Anthropic, OpenAI, Google, Microsoft, Amazon, xAI and Mistral all have platforms for building agents, and frameworks like LangChain build them without tying to one model. As of August 2026 deployments exist; general adoption does not.

The default implementation would be an agent running a simple process end to end, deciding and implementing, with a human in the loop (HIL) managing the exceptions. A different type would be an agent as the interface between people and the systems, capturing data in natural language where the work happens.

Steps:

  1. Selection of processes
  2. Assessment and documentation
  3. Rationalisation
  4. Building, testing and deployment
